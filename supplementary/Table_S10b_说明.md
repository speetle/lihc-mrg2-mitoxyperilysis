# Table S10b 说明

**用途**：R1-M8。原稿以「10 折 C-index 的均值 ± SD/√10」报告完全嵌套表现，并把 0.576 描述为「约 2.4 个标准误高于随机」。本表以标准口径替换之：

- **主统计量 = pooled out-of-fold C-index**：把十折 held-out 线性预测拼成一条向量，对全部 360 例患者算**一个** C-index（各折事件率不同时，对折值取均值是有偏的）。
- **10 个独立随机划分**：对折分配用 10 个不同种子重复整条嵌套流程，报划分间均值与 SD，替代「SD/√10」。
- 划分 0 的折分配与内部 bootstrap 种子与原稿完全一致，其折内 C-index 均值复现沉积的 0.576，作为本表的自我一致性校验。
